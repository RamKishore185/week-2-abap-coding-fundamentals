# Upload guide

1. Review every file and adapt it to your SAP release.
2. Execute and test the ABAP report in your SAP system.
3. Add real screenshots to `Screenshots/`; do not use mock screenshots.
4. Update test cases with actual Pass/Fail and observed results.
5. Upload the folder contents to your GitHub repository.

Suggested repository name: `week-2-abap-coding-fundamentals`
Suggested description: `Week 2 SAP ABAP report development learning project: sales-order monitor with Open SQL and SALV.`
